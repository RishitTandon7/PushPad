# Example projects

Two tiny projects for trying PushPad. Paste the PushPad repo URL into the deploy bar, open "Options", and set the folder:

| Example | Folder | Type PushPad detects |
|---|---|---|
| `static-site` | `examples/static-site` | static (has `index.html`) |
| `node-app` | `examples/node-app` | node (has a `start` script) |

The demo chips on the PushPad home page fill these in for you.
