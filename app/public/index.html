06 / FAQ
Questions

        

          
A self-hosted mini Vercel. Pushing a Git branch makes Jenkins build it and Terraform create a real EC2 server with its own URL. ngrok tunnels your laptop to the internet; PushPad builds real cloud servers that keep running without your laptop.

          
A cleanup job runs every 5 minutes and destroys any server whose branch is gone, plus any preview older than 24 hours. You pay for one Jenkins server, one prod server, and previews that live minutes.

          
Before each prod deploy the last good build is saved. If the new build fails its health check, Terraform re-applies the saved build and the pipeline fails loudly.
